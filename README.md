# SQL Data Exploration Project

## Overview
An exploratory SQL analysis of a global COVID-19 dataset, examining death rates, infection rates, vaccination progress, and geographic trends across countries and continents. The goal was to extract meaningful public health insights from raw data and prepare the results for visualization in Tableau.

## Dashboard
View the completed Tableau dashboard here:
https://public.tableau.com/app/profile/bray.demonbreun/viz/Covid-19DataTableauProject1/Dashboard1

## Key Questions Explored
1. What does the death percentage rate look like over time in the United States?
2. Where and when was the peak death percentage rate in US territories?
3. What is the total COVID-19 case rate relative to population in the United States?
4. Which countries have the highest infection rate compared to their population?
5. Which countries have the highest total death count?
6. Which continent has the highest total death count?
7. What is the overall global COVID-19 death rate?
8. What percentage of the global population has been vaccinated?

## Skills Demonstrated
Joins, CTEs, Temp Tables, Window Functions, Aggregate Functions, Creating Views, Converting Data Types, CASE logic, data type troubleshooting

## Tools
SQL Server (T-SQL), Tableau

## Notes
This project was completed as part of a graduate-level data analytics portfolio. The dataset does not account for individuals contracting COVID-19 multiple times. Results should be interpreted as exploratory rather than definitive public health conclusions.
